PROJECT SOLE WORKFLOW

1.  Create/Update SOLE projects_log.json.
	- keys : 
		- created = UTC datetime :: YYYY-mm-ddTHH:MM:ss.ssssss+00:00
		- title_code = title code :: #_
		- jp_title = title in Japanese :: A_
		- proj_code = title_code + "." + jp_title :: #_.A_

	- Create project folder; 
		named : proj_code :: #_.A_

2.  Create Box folders for the current term.
	
	ch_0 = first chapter of title for the current term :: #_
	ch_1 = last chapter of title for the current term :: #_
		optional in the case of singe-chapter terms
	term_folder = proj_code + " " + ch_0 {+ "_" + ch_1} ::  #_.A_ #_-#_
	ch_code_en =  chapter code for English files :: #(10)_en_#(4)
		(padded title code; 10 chars 
			+ "_en_" 
			+ padded chapter number; 4 chars) 
		eg. 0000233680_en_0004
	ch_code_jp = chapter codes for Japanese files :: #(10)_jp_#(4)
		(padded title code; 10 chars
			+ "_jp_" 
			+ padded chapter number; 4 chars) 
		eg. 0000233680_jp_0004

2.1. Proofreading folder
	Box folder tree :

	Project SoleTLTS 
	+ Term##_
	  + 06 Proofreading
	    + term_folder
	      + PDF files
	
	PDF filename : ch_code_en

2.2. Typesetting folder; PSD files, except thumbnails (by others)
	Box folder tree :

	Project SoleTLTS 
	+ Term##_
	  + 03 Typeset PSD
	    + term_folder
	      + chapter folder
	        + PSD files

	chapter folder : ch_code_en
	PSD file : name of file; padded page number; 4 chars :: #(4) 

3.  Download reference files.
	Box folder tree :

	Project SoleTLTS
	+ Term##_
	  + 01_日本語JPEG (Japanese JPEG)
	    + term_folder
	      + ch_code_jp	
	
	Since it's possible that multiple typesetters work on a single chapter, assigned to different non-overlapping chapters, chapter files to be downloaded is limited to personal assignment.

4.  Prepare files

	term = current term :: ##_
	jpeg_ref_jp = folder containing reference Japanese JPEG files by chapter; as downloaded from Box
		term + " JPEG" :: ##_ JPEG
	work_en = folder containing working PSD files; by term by chapter
		"T" + term + " - " + ch_code_en
	compile_en = folder containing set of PSD files, and PDF file of the set of PSD files for the current revision number
		"COMPILED " + rev_num :: COMPILED #_
	file_num = page number of file in the set; starts at "0001.psd" for cover page :: #(4)  padded 4 chars
